# How to Upload a Document

[← Back to Developer Guide](../index.md)

## Before you begin
- Make sure the document is no larger than 50 MB.
- Make sure the file is in PDF or DOCX format.

## Procedure
1. Sign into SecureVault account.
2. Select **Upload**.
3. Choose the file to upload. 
4. Select **Upload**.

## Expected result
The uploaded document appears in your document list.
