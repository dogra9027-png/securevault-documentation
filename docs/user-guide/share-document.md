# How to Share a Document

[← Back to Developer Guide](../index.md)

## Before you begin
- Have a SecureVault account. 
- Make sure the recipient has a SecureVault email address.

## Procedure
1. Select the document that needs to be shared.
2. Select **Share**.
3. Enter the recipeint's SecureVault email address. Select View or Edit permission. 
4. Select **Share**.

## Expected result
The shared document appears in **Shared with Me**.
