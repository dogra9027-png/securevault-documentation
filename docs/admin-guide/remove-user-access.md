# How to Remove User Access

[← Back to Developer Guide](../index.md)

## Before you begin
- Have administrator access to SecureVault.

## Procedure
1. Select the user.
2. Select the document. 
2. Remove **View** or **Edit** access.
3. Select **Save**.

## Expected result
The user's access to the document is removed.
