# How to Create a User

[← Back to Developer Guide](../index.md)

## Before you begin
- Have an administrator access to SecureVault. 

## Procedure
1. Select **User Management**.
2. Select **Create User**.
3. Enter user details.
4. Select **View** or **Edit** permission for the user.
5. Select **Save**.

## Expected result
The new user appers in the Users list.
