# How to Give a User Access

[← Back to Developer Guide](../index.md)

## Before you begin
- Have administrator access to SecureVault.

## Procedure
1. Select the user.
2. Select the document to grant the user access.
3. Select **Edit** or **View** permission.
4. Select **Save**.

## Expected result
The user has the selected permission for the document.
