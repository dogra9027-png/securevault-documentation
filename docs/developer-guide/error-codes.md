# Error Codes

[← Back to Developer Guide](../index.md)

## 400 Bad Request

`400 Bad Request` is returned when the API request contains invalid or missing data and SecureVault cannot process the request.

## 404 Not Found

`404 Not Found` is returned when the requested resource cannot be found.

## 409 Conflict

`409 Conflict` is returned when the API request conflicts with the current state of a resource, such as when an operation would create a duplicate resource.

## 500 Internal Server Error

`500 Internal Server Error` is returned when SecureVault encounters an unexpected error while processing a valid API request.
